# DrugsEngine

DrugsEngine is the core backend and platform project for the Drugs Engine ecosystem.

## Overview
This repository contains the main C# implementation, domain logic, and core services for the Drugs Engine platform.

## Features
- Core backend services
- Business logic and orchestration
- Domain modeling and persistence layers
- Integration with supporting Drugs Engine services and infrastructure
